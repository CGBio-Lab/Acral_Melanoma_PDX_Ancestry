# admixture/

The following files are expected here:

- `genotype_1000g_geno_mind.5.Q` — ancestry proportions per sample for K = 5 (produced by `scripts/admixture.md`)
- `genotype_1000g_geno_mind.5.P` — allele frequencies of the inferred ancestral populations (produced by `scripts/admixture.md`, not used by the plots)
- `admixture.pdf` — ADMIXTURE barplots, Fig. 1E (produced by `scripts/create_plots.py`)
- `admixture_table.csv` — per-sample ancestry proportions, Supplementary Table 12 (produced by `scripts/create_plots.py`)
